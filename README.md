# 스트레칭 타이머

휴대폰에서 쓰는 스트레칭용 인터벌 타이머입니다.

- 10초 스트레칭 → 2초 휴식을 2~12회 반복
- 스트레칭 중 매초 알림음
- 10초가 끝날 때마다 "하나, 둘, 셋 …" 음성 안내
- 시작 전 3초 준비 (끌 수 있음)
- 타이머가 도는 동안 화면 꺼짐 방지

## 사용법

GitHub Pages 주소를 휴대폰 브라우저로 열고 반복 횟수를 고른 뒤 **시작**을 누르세요.
홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

> 아이폰은 무음 스위치가 켜져 있으면 알림음이 들리지 않습니다.

## 배포

`index.html` 하나로 된 정적 페이지라 빌드 과정이 없습니다.
저장소 **Settings → Pages**에서 `main` 브랜치의 `/ (root)`를 선택하면 배포됩니다.
